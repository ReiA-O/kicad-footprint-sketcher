# 操作ガイド

[READMEへ戻る](../README.md)。Windows向け試用版の操作を説明します。寸法はmm、角度は度です。座標はXが右、Yが下を正とし、角度入力欄は反時計回りです。

## 下絵から作る（10 mmサンプル）

同梱の合成画像で、校正からKiCad出力まで試せます。PNGとJPEGで同じ手順を使います。

1. 「下絵を開く…」で [`land-pattern.png`](../examples/stage1/land-pattern.png) または [`land-pattern.jpg`](../examples/stage1/land-pattern.jpg) を選びます。
2. 校正方式を **「2点・共通縮尺（補助）」** にし、「校正の2点を選ぶ」を押します。画像の校正点A・Bの十字の中心を順にクリックします。
3. 「横／共通の実距離 (mm)」へ `10` を入力し、Enterまたは「校正を適用」を押します。点間は600 px、縮尺は約0.016667 mm/pxです。
4. 「画像の中央を原点に」を押します。
5. 右側に次の番号・幅・高さ・角度・Rを入力し、「パッドを配置」を押して、各パッド中心の十字をクリックします。右クリックで連続配置を終え、次のパッドを設定します。

   | 番号 | 中心X / Y (mm) | 幅 × 高さ (mm) | 角度 | 角R (mm) |
   | --- | --- | --- | --- | --- |
   | 1 | −2.5 / −1.0 | 1.6 × 1.2 | 0° | 0 |
   | 2 | +2.5 / +1.0 | 2.0 × 1.2 | 30° | 0.25 |

6. フットプリント名を `Stage1_SMD_Demo` にします。自分の出力先に `.pretty` フォルダーを作り、「ファイル → KiCadへ書き出す…」でそのフォルダーを選びます。
7. KiCad 10のフットプリントエディターで、出力した `.kicad_mod` をインポートします。番号・位置・寸法・角度・`F.Cu / F.Paste / F.Mask`を確認します。[出力例](../examples/stage1/Stage1.pretty/Stage1_SMD_Demo.kicad_mod)と照合できます。

クリック位置は表示倍率と選び方に依存します。表の座標は十字の中心を選んだ場合の値です。拡大して選ぶか、「属性・レイヤー・図形…」の位置X/Yで数値を確認できます。この2パッドのサンプルにはCourtyardがありません。

## 校正・原点・表示

標準は「横2点＋縦2点（標準）」です。「横2点＋縦2点を選ぶ」を押し、横X1/X2、縦Y1/Y2の順に選びます。横の2点目は1点目と同じY、縦の2点目は1点目と同じXに固定されます。それぞれの実距離をmmで入力して適用し、最後に「原点を選ぶ」または「画像の中央を原点に」を使います。

補助の2点共通縮尺は任意方向の2点と1つの実距離を使います。いずれの方式も画像自体の回転・せん断・台形補正は行いません。校正に使う寸法と単位はデータシートで確認し、インチ表記ならmmに換算して入力します。

| 操作 | 方法 |
| --- | --- |
| 拡大・縮小 | キャンバス上のホイール、または「−」「＋」 |
| 表示の移動 | 中ボタンを押しながらドラッグ |
| 全体へ戻す | 「全体表示」 |
| 操作を中断 | Escまたは右クリック |

ズーム・表示移動は実寸や校正値を変更せず、校正点を選ぶ途中にも使えます。

## パッドの配置と編集

校正と原点指定の後、「矩形パッド」または「角丸パッド」で対角2点をドラッグします。同じツールで連続作成でき、番号には次の未使用番号が入ります。寸法を先に決める場合は、W/H・角度・Rを入力して「数値サイズで配置」または「パッドを配置」を使い、中心をクリックします。右クリック・Esc・「選択/移動」で連続配置を終了します。

「選択/移動」でパッドを選び、ドラッグで移動、選択枠の四隅で矩形・角丸のサイズを変更します。右側のW/H・角度・Rを入力してEnter、または「選択パッドに適用」で数値編集できます。サイズを縮めてRが短辺の半分を超えた場合、Rも縮みます。

番号だけを変えるときは、1個選択して上部の「選択番号」を書き換え、Enterまたは「番号を変更」を押します。一覧の番号をダブルクリックしても編集でき、Enterで確定、Escまたはフォーカス移動で取り消します。

### 複数選択・コピー・整列

- 空白からドラッグすると、選択矩形に中心が入った対象をまとめて選びます。既存パッド上からのドラッグは移動です。Ctrlクリックで個別に追加・解除でき、一覧でも複数選択できます。
- 矩形・角丸の複数選択へW/H・角度・Rを適用できます。番号は元のまま保持します。Customを含む一括数値適用は非対応です。
- 「コピー」→「貼り付け」で、元の属性と複数対象の相対配置を保持し、新しい未使用番号で複製します。複数対象の貼付基準は各中心の平均です。右クリックまたはEscで連続貼付を終了します。
- 「中心スナップ」が有効なら、移動時に非選択パッドの中心X/Yへ合わせます。Shiftドラッグで水平・垂直に移動を制限できます。
- 「横中心揃え」は中心Yを選択全体の平均へ、「縦中心揃え」は中心Xを平均へそろえます。「横等間隔」「縦等間隔」は3個以上で、対象軸の両端中心を固定して中間を均等配置します。
- 「X軸で反転コピー」は原点を通るX軸で上下反転、「Y軸で反転コピー」は左右反転します。同じ面・レイヤーを保ち、新番号で複製します。

整列・等間隔は一回の位置変更です。後の編集でも関係を保つには、後述の拘束を使います。

### Undoとキーボード

| キー | 操作 |
| --- | --- |
| Ctrl+Z | 1操作戻す |
| Ctrl+C / Ctrl+V | コピー／貼り付け |
| Ctrl+S | 編集用プロジェクトの保存 |
| Delete | 選択対象の削除 |
| Esc / 右クリック | 配置・貼付・作図・ドラッグ等を中断 |

文字入力欄では文字のコピー／貼付などを優先します。Undoは確定した作成・移動・寸法変更・校正・原点指定・合体・貼付・整列などを1操作ずつ戻します。進行中のドラッグはプレビューを取り消し、未適用の校正点は最後の1点を戻します。下絵を切り替えるとUndo履歴はクリアされます。Redoはありません。

Enterの反映先は現在の状態によって変わります。パッド選択中は選択対象へ、配置中は次に置くパッドへ反映します。未選択時のW/H入力からは数値サイズ配置に進みます。フィレットRのEnterは角選択待ちへ進み、実際の加工は角クリックで確定します。

## 属性・レイヤー・図形のパネル

上部の「属性・レイヤー・図形…」から、次の5タブを開きます。キャンバス／一覧で対象を選び、各タブで編集します。

| タブ | 操作 |
| --- | --- |
| 属性・穴・開口 | 位置、種別、形状、面、穴、Mask／Paste |
| 図形・レイヤー | 作図、表示、編集ロック |
| コピー・接続 | 基準点コピー、点／線対称、銅箔接続、Paste分割 |
| 拘束 | 関係や寸法の追加・変更・解除、状態表示 |
| 文書 | Reference／Value、プロジェクトの保存・読込み |

### 種別・穴・面・開口

「属性・穴・開口」の種別は `smd`、めっき穴の `thru_hole`、非めっき穴の `np_thru_hole`。形状は `auto / rect / roundrect / circle / oval` です。穴なしSMDは穴の幅／高さを0、丸穴は同じ正の寸法、長穴は異なる正の寸法をmmで指定します。NPTHの端子番号は空欄になります。

SMDの面はF／Bです。Mask・Pasteはチェックで有無を指定します。PTH／NPTHは `*.Cu` と、Mask有効時の `*.Mask` を使います。Mask／Paste片側拡縮はmm、Paste片側比率は `0.1 = 10%` です。Paste寸法には比率とmm拡縮の両方を反映します。

「選択へ位置・穴・面・開口を適用」または属性欄のEnterで確定します。複数選択では個々の位置を保ち、共通属性を適用します。未選択時や配置ツール中の設定は、次に置くパッドに使います。円の幅だけを変更すると高さも同じ直径へ追従します。

### 作図とレイヤー

「図形・レイヤー」で図形・作図レイヤー・線幅・塗りつぶしを選び、「キャンバスで作図」を押します。下絵がある場合は先に校正と原点指定を済ませます。

- `rect / roundrect / line / circle` はドラッグで作図します。角丸図形のRは、このタブの「作図する角丸図形のR (mm)」を使います。
- `arc` は始点・中間点・終点の3点を順にクリックします。同一直線の3点は使えません。
- `polygon` は3点以上をクリックし、「多角形を確定」またはキャンバス上のEnterで閉じます。自己交差は拒否します。
- Escまたは右クリックで進行中の作図を取り消します。

F／BそれぞれのCu、Paste、Mask、SilkS、Fab、CrtYdを扱います。独立したMask／Paste開口は、該当レイヤーに塗りつぶし図形を作図します。各レイヤーの表示チェックと「編集ロック」で、表示と変更可否を管理します。

## 合体・フィレット・銅箔接続

同じ端子の矩形・角丸を複数選択し、右側の「合体後の端子番号」を入力して「選択図形を合体」を押すと、Cu／Maskを1番号のCustomパッドへまとめます。元のPaste開口は独立して残り、キャンバスでは金色の点線で表示します。

Customを1個選び、「フィレットR (mm)」を入力して「角を選んでフィレット」を押し、丸めたい角の丸印をクリックします。選んだ角だけを加工し、続けて別の角も選べます。Escまたは右クリックで終了します。

Customの青い十字は形状内の接続アンカーで、重心ではありません。移動・コピー・対称・拘束などの基準はこの接続点です。番号・角度・位置・選択角フィレットは編集できますが、全体W/H・全体Rと四隅リサイズは非対応です。寸法を直す場合は合体前へUndoし、元形状を編集します。

元の端子番号を残したまま接続するときは、「コピー・接続」の「選択した同一ネット端子を銅箔接続」を使います。同じ面のSMDを複数選び、接続幅を正のmm値で指定すると、一覧順の接続点を丸端Cuで結びます。幅0は接続線を足さず、既につながった形状だけを使います。元パッド・番号・Mask／Pasteを残し、代表番号のCu専用Customを追加します。

ネット情報は推定しないため、同一ネットの端子を自分で指定します。分離形状・点だけの接触・穴を含む合成は拒否します。別ネット間用のNet-tieは作成しません。

## 任意の基準点コピー・対称・Paste分割

「コピー・接続」で点A／Bと対称中心をmmで入力するか、「点Aを選ぶ」「点Bを選ぶ」「中心を選ぶ」でキャンバスから指定します。

| 操作 | 動作 |
| --- | --- |
| 点A→点Bへコピー | AからBへの移動量で複製 |
| 指定中心で点対称コピー | 指定中心の周りに180°反転 |
| 点A–点Bの軸で線対称コピー | 2点を通る任意の直線に対して反転 |

同じ面のレイヤーを保ち、通常は新しい未使用番号を使います。「コピー先でも元の端子番号を維持する」を有効にすると元番号で複製します。

Paste分割は通常SMDまたはCustomを1個選択し、横数・縦数を正の整数、窓間隔を正のmm値で指定して実行します。通常SMDはCustomへ変換し、Cu輪郭とMaskを保ちます。元開口の向きに沿う格子へ分割し、条件を満たせない場合は変更を拒否します。分割欄のEnterでも実行できます。

## 拘束を保持する編集

「拘束」タブで対象、種類、必要な数値を指定して追加します。

| 選択数 | 拘束 |
| --- | --- |
| 1対象 | X／Y位置、幅、高さ、角度、R、固定 |
| 2対象 | 中心一致、水平、垂直、点対称、水平／垂直軸対称、等幅、等長、等高、等寸法、中心間距離、X／Y間隔 |

対象の順序はクリック順ではなく一覧順です。対称中心／軸位置には「コピー・接続」タブの対称中心を使います。関係は対象の中心、Customでは接続アンカーに対するものです。中心の対称拘束だけでは輪郭・角度・寸法を反転／一致させないため、形状の反転は対称コピー、寸法の保持は等寸法と組み合わせます。

円のRは実半径、線の幅／等長は実際の線の長さです。Customで拘束変更できるのはX・Y・角度の3自由度です。

拘束一覧から選択して変更・解除できます。寸法欄のEnterは、一覧で選択済みなら変更、未選択なら新規追加になります。未拘束／完全拘束と残り自由度を表示し、矛盾や解けない変更は理由を示して直前の正常形状へ戻します。任意の拘束系の解や全解探索を保証するものではありません。

未適用の校正点は適用または取り消してから編集します。拘束を満たさないプロジェクトの読込み・保存・KiCad出力は停止します。拘束参照のある図形を合体する場合は、先に該当拘束を解除します。削除時に参照拘束の解除が必要なら確認を表示します。

## PDF・下絵の差し替え

「ファイル → PDFのページ／範囲を下絵に…」でPDFと1始まりのページ番号を選びます。範囲はラスタ画像の左上を基準に `X,Y,幅,高さ` の整数pxで入力し、空欄ならページ全体です。読み込んだ後は実寸校正と原点指定を行います。PDFの文字・寸法・パッドは自動認識しません。

既存の図形を残して画像だけを追加・交換する場合は、「ファイル → 図形を残して下絵を追加・差替え…」を使います。PNG／JPEG／PDFに対応し、既存図形と拘束のmm座標を保ちます。校正と原点はリセットされるので新しい下絵で指定し直します。この最初の原点指定では既存図形を動かしません。

## 保存・KiCadでの確認

| ファイル | 用途 |
| --- | --- |
| `.kfsproj` | 再編集用。下絵画像・校正・原点・図形・拘束・文書属性・保持情報を内包 |
| `.kicad_mod` | KiCadへ渡すフットプリント。下絵・校正・拘束は含まない |

「ファイル → プロジェクトを保存…」またはCtrl+Sで `.kfsproj` を保存します。PDFを使った場合は選択した下絵画像を保存し、元PDFは内包しません。「プロジェクトを開く…」で作業を再開します。

KiCad出力はフットプリント名を指定し、「ファイル → KiCadへ書き出す…」で作成済みの `.pretty` フォルダーを選びます。同名出力は確認後に置き換えます。初回は新しい出力先を使い、元ファイルも保存してください。

KiCad 10のフットプリントエディターから、出力した `.kicad_mod` をインポートします。番号・座標・寸法・角度・穴・レイヤー・Mask／Paste・Courtyardを確認し、Footprint Checkerも実行します。ライブラリとして継続利用する場合は `.pretty` をKiCad側のフットプリントライブラリへ登録します。

「ファイル → 新規」は下絵なしのmm座標で編集を始めます。新規・別ファイルの読込み・終了では、プロジェクトに未保存の変更があれば確認します。

## 制限と既存ファイルの扱い

「ファイル → KiCadフットプリントを開く…」はKiCad 10.0系の形式 `20260206` が対象です。読み込み時に要素の分類を表示します。

| 分類 | 扱い |
| --- | --- |
| 編集可能 | 対応する基本パッド・図形・単一輪郭Custom等。Reference／Valueは文字値を編集し、位置・効果等は保持 |
| 保持のみ | 未対応の特殊パッド・属性・要素は元のS式を保持。直接編集やキャンバスでの完全再現はしない |
| 保全不能な変更 | 保持要素の参照を壊すおそれがある変更は理由を表示して保存停止 |

Customと所属Paste開口はUUIDと非表示プロパティで関連付けます。所属情報のない旧出力や独立の空番号開口を、位置・並び順で自動関連付けはしません。UUIDだけを外部更新して所属情報と不整合になったファイルや、旧プロジェクトの保持情報の整合を確認できない場合は読み込みを停止します。元ファイルを残し、元の作成プロジェクトから出力し直してください。

任意のKiCad要素を編集できるツールではありません。Customの全体リサイズ、Redo、一般グリッド、画像の回転・せん断・台形補正、Net-tieは未対応です。クリック誤差や数値計算の観測結果を、任意の設計の精度保証として扱わないでください。

## 起動時の確認

リポジトリのルートで、次を順に確認します。

```powershell
py -3.14 --version
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe -m tkinter
.\.venv\Scripts\python.exe -m footprint_sketcher
```

- `py -3.14` が見つからない場合は、Python 3.14の導入とランチャーを確認します。
- `.venv` がない場合は、READMEの仮想環境作成から実行します。
- Tkテスト画面が開かない場合は、PythonのTcl/Tk構成を確認します。
- `ModuleNotFoundError` が出る場合は、起動に使う同じ `.venv` のPythonで `-m pip install -r requirements.txt` を実行します。

解決しない場合は、コマンドの結果と再現手順を[GitHub Issues](https://github.com/ReiA-O/kicad-footprint-sketcher/issues)へ記載してください。個人名・ローカルパス・機密情報を除いてから共有します。

詳しい検証結果は[Windows自己レビュー記録](verification/windows-strict-review-20261123/README.md)、採用範囲は[要件と実装の対応](requirements-audit-20261123.md)、公開履歴の変更は[公開版の説明](PUBLICATION.md)を参照してください。
