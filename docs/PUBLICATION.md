# 公開版のライセンスと匿名化

この公開版は、利用・改変を許可し、権利者の事前許可のないプログラム本体の再配布を禁止する独自ライセンスです。GitHubの規約と標準機能で認められるサービス内の閲覧・Fork等は例外です。詳しくは[LICENSE](../LICENSE)を参照してください。生成・編集したフットプリントやプロジェクト自体には、この再配布禁止を適用しません。

## 検証記録の扱い

検証ログ、検証コード、ZIP・専用プロジェクト内のユーザー名と環境の絶対パスを匿名表記へ置き換えました。`<REPO>`、`<WORKSPACE>`、`<USER_HOME>`、`<TEMP>`などは公開用のラベルです。過去の検証コードを再利用する場合は、自分の作業先を指定してください。

匿名化は過去の公開ブランチの履歴にも適用しています。これに伴いコミット番号と署名、匿名化したファイル・ZIPのハッシュは変わります。記録中のGitコミット識別子は実行当時の識別情報であり、匿名化後の公開履歴を示す番号ではありません。匿名化前の履歴へ直接誘導するGitHubリンクは、現在の公開版を参照するリンクへ変更しました。

既存のWindows185件・KiCad148出力照合は、匿名化前の実行で観測した結果です。今回の個人情報除去でアプリ本体と既存テストのコードは変更していません。画像・フットプリント形状を変更せず、変更した内容は検証記録の環境識別情報と公開条件です。匿名化した添付データを元の生データと同一バイトの記録とは扱いません。

元の履歴と対応表は公開リポジトリへ含めず、管理者の手元のバックアップに保管しています。

## 公開元で除去できる範囲

公開ブランチとその到達可能な履歴は匿名化の対象です。GitHubが管理する古いPR参照・コミットのキャッシュや、すでに取得された他人のclone／forkまでの完全な消去を保証するものではありません。GitHub上の内部参照やキャッシュには、GitHub側の対応が必要になる場合があります。

2026年11月23日の再取得確認では、GitHub管理の `refs/pull/1/head` と `refs/pull/2/head` が匿名化前の履歴を参照していました。PR本文・会話本文は匿名化済みですが、旧PR差分を含むGitHub全域からの削除は未完了です。これらの参照は通常のブランチ更新では変更できません。GitHub側の対応が必要で、削除対象となるかはGitHubの判断によります。[GitHubの説明](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository)を参照してください。

履歴変更前にcloneした場合は、新しくcloneし直してください。古い履歴をmergeしたりpushしたりすると、除去した情報が戻るおそれがあります。

## 今後の確認

公開する前に、標準ライブラリだけで実行できる次のチェックを使用できます。

```sh
python tools/check_publication.py
python tools/check_publication.py --history
```

追跡ファイルまたは全ローカル参照の履歴を、ZIP・専用プロジェクトの内部まで確認します。一般的な環境の絶対パス、秘密鍵、主要なトークン形式などを検出します。画像の内容や、あらゆる秘密情報・任意の個人名を判定する仕組みではないため、画像と添付ファイルの目視確認も必要です。
