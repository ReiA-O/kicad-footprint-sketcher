# クリップボード・PDF取込みのバグ再点検（2026年11月23日）

対象は[PR #4](https://github.com/ReiA-O/kicad-footprint-sketcher/pull/4)です。修正前の基準は `3efa177329b3417424c9c51b5670a76c4e4a5c55`。クリップボードとPDFビューアー、および周辺の下絵読込・プロジェクト保存再開・Undoを確認しました。

以前のWindows 220件の成功を今回の修正へ流用せず、追加した回帰試験とともにWindows CIで再実行します。対象コミットと最終結果はPR本文・Actionsで記録します。本人の手操作による受入確認とは区別します。

## 修正した問題

| 問題 | 再現条件と修正前の動作 | 修正 |
| --- | --- | --- |

## 検証方法

- 破損PNGは小さな合成データを使い、Pillowの実デコーダーで再現しました。Windows clipboardのネイティブ入口だけを模擬し、実ユーザーのclipboardは読み書きしていません。
- プロジェクト内画像は実ZIP、保存再開は実ファイルで確認します。上限試験はPNGヘッダーを使い、大きな画素領域を実際に確保しません。
- GUI回帰では、確認の拒否、読込失敗、同一画像の取込み、保存成功／失敗、Reference／Valueの再反映、校正方式と距離欄の一致を確認します。
- PDFでは追加で、左ドラッグ途中のホイール拡大、中ボタン移動後の逆方向選択、親ウィンドウ終了時のモーダル解除を確認します。これらは追加検証であり、再現した不具合として数えていません。
- 構文・差分書式・公開内容スキャン、既存のモデル・出力・プロジェクト往復も再確認します。

主な回帰試験は[clipboard](../../tests/test_clipboard_reference.py)、[画像読込・Undo](../../tests/test_gui_interactions.py)、[プロジェクト](../../tests/test_persistence.py)、[文書状態](../../tests/test_reference_import_gui.py)、[PDFビューアー](../../tests/test_pdf_viewer.py)です。
